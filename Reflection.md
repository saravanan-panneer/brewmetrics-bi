# Reflection

The BrewMetrics BI project gave me practical experience in building a business intelligence solution from data modelling through to dashboard development. One of the main lessons I learned was the importance of creating a proper star schema before developing the report. Separating the Fact_Sales table from the Dim_Date, Dim_City and Dim_Product tables made it easier to analyse the data using different dimensions.

GitHub Copilot was useful during the DAX development stage. It helped me generate initial ideas for measures such as Total Sales, MoM Growth %, Running Total Sales, City Sales Rank and Average Transaction Value. However, the generated formulas still required testing. I had to check the field names, relationships and filter context to ensure that the calculations worked correctly in my Power BI model.

The dashboard development also helped me understand the importance of presenting information clearly. KPI cards provided a quick overview of performance, while charts and slicers allowed the user to explore sales by month, city, product and category. Testing the dashboard helped me identify areas where formatting and visual choices could be improved.

Using GitHub throughout the project was another important learning experience. Making separate commits for the model, DAX measures, dashboard and documentation created a clear record of the development process.

Overall, this project improved my understanding of Power BI, DAX, data modelling and version control while showing me how AI tools can support, rather than replace, technical decision-making.
